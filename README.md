# 词搭子 PWA

适用于安卓平板的单词学习应用。无需登录，单词、资料和学习进度保存在当前设备浏览器中；拍照识词使用腾讯云 OCR 联网识别，发音在设备语音不可用时自动切换到国内联网音频。

## 本地预览

在 `dist` 目录启动任意静态文件服务器后访问即可。不能直接双击 `index.html`，因为 PWA 离线缓存需要 HTTP/HTTPS。

## 发布到 GitHub Pages

将 `dist` 目录内的全部文件发布到 GitHub Pages。站点使用相对路径，可部署在仓库子目录下。

## 安卓平板安装

用 Chrome 打开发布网址，点击浏览器菜单中的“添加到主屏幕”或页面中的“安装到桌面”。首次打开后，背词、进度、资料阅读可离线使用；拍照识词和 B 站视频需要联网。

## 联网 OCR

腾讯云 Web 函数代码位于 `backend/tencent-ocr-function`。部署后，将函数的 HTTPS 地址写入 `dist/ocr-config.js`。
